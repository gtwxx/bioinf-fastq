# Обработка и анализ данных формата FASTQ

## Используемые инструменты
* **Python 3**. Встроенные библиотеки `pathlib` и `typing`. Сторонние модули не использовались.
* **Trimmomatic (v0.39)** — утилита командной строки для контроля качества и обрезки прочтений.

## Описание решения по заданиям

### Задание 1. Парсинг FASTQ и базовая статистика
Написан парсер (функция `analyze_raw_fastq` в скрипте). Формат FASTQ подразумевает, что данные одного прочтения занимают 4 строки. Алгоритм проходит по файлу один раз. Проверяется остаток от деления номера строки на 4 (`line_num % 4 == 1`), чтобы извлечь только саму нуклеотидную последовательность. Затем считаются количество и длины.

### Задание 2. GC-состав
Внутри итератора при прохождении нуклеотидной последовательности используется строковый метод `.count()` для подсчета Гуанина ('G') и Цитозина ('C'). Формула: `(G + C) / Общая_длина_сиквенсов * 100`. 

### Задание 3. Качество по шкале Phred 
Парсер считывает 4-ю строку каждого прочтения (`line_num % 4 == 3`). В формате Phred+33 качество кодируется ASCII символами. Для извлечения реального числового качества на 10-й позиции берется символ с индексом 9, и к нему применяется стандартная формула раскодировки: `ord(char) - 33`.

### Задание 4. Тримминг данных (Trimmomatic)
Для выполнения этого задания использовалась программа Trimmomatic через командную оболочку (bash).

**Команда 1 (Окно 5, качество 30):**
```bash
java -jar trimmomatic-0.39.jar SE -phred33 reads.fastq trimmed_sw.fastq SLIDINGWINDOW:5:30
```
*(Примечание: полученный файл `trimmed_sw.fastq` используется скриптом для подсчета минимальной, максимальной и средней длины отфильтрованных прочтений).*

**Команда 2 (Добавлен фильтр длины 60):**
```bash
java -jar trimmomatic-0.39.jar SE -phred33 reads.fastq trimmed_minlen.fastq SLIDINGWINDOW:5:30 MINLEN:60
```
*(Примечание: скрипт парсит выходной файл `trimmed_minlen.fastq`, чтобы подсчитать оставшееся число прочтений).*

Математика подсчета (сколько ридов удалилось и длины выживших) реализована в функции `analyze_trimmed_data()` с помощью генераторов списков `list comprehension` для максимальной скорости работы.
